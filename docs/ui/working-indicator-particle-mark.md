# 工作中粒子标识

## 范围

会话「工作中」状态左侧的 `ChatLoadingOrbs` 自定义动画：105 个粒子在球体与品牌字母之间循环变形。

## 规则

- 品牌字母为 **W**，与 WCode 标识一致，不再使用 Z。
- 字形使用 28 个锚点组成 W：左外侧下斜、左内侧上斜、右内侧下斜、右外侧上斜四条笔画。
- 球体阶段、变形时长、W 停留时长、反向变形与 8240ms 循环周期保持现有节奏，不因换字形改变动画速度。
- 减少动态效果（prefers-reduced-motion）时直接显示静态 W，不播放球体或变形。
- 粒子颜色继续使用 `text-brand`，圆点半径、透明度与投影保持原样。
- 图标槽保持 16px，不改变「工作中」文案、计时器与布局对齐。

## 验收

1. 动画进入 W 停留阶段时，28 个锚点组成可辨认的 W，起止点不超出 20×20 viewBox。
2. 球体阶段与变形时间轴不变；减少动态效果时显示静态 W。
3. 桌面与手机 Web、深色与浅色主题下粒子可见，图标槽不引起文案或计时器位移。
